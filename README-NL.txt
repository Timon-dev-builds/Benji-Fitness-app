FORGEFIT — GRATIS FITNESS- EN VOEDINGSTRACKER
==============================================

Inbegrepen:
- Voeding handmatig loggen: kcal, eiwit, koolhydraten en vet
- Workout logs: oefening, sets, reps, gewicht en datum
- Gewicht en lichaamsvetpercentage loggen
- Persoonlijke records per oefening
- Gewicht- en vetpercentagegrafieken
- Mifflin-St Jeor caloriebehoefte schatten en dagdoelen instellen
- Lokale opslag, JSON-back-up exporteren/importeren
- Basis offline ondersteuning na de eerste online laadbeurt

PRIVACY
Gegevens worden lokaal in de browser van het apparaat opgeslagen. Er is geen account, analytics of synchronisatie. Gegevens worden niet automatisch gedeeld met andere telefoons. Maak geregeld een back-up. Bij het wissen van browsergegevens kunnen opgeslagen gegevens verloren gaan.

GRATIS HOSTEN MET GITHUB PAGES
1. Maak gratis een account op https://github.com als je er nog geen hebt.
2. Maak een nieuwe repository aan, bijvoorbeeld "forgefit".
3. Kies Public (nodig voor gratis GitHub Pages op het standaard gratis plan).
4. Upload ALLE bestanden uit deze map naar de hoofdmap van de repository:
   index.html, manifest.json, sw.js en icon.svg.
5. Open in GitHub de repository: Settings → Pages.
6. Bij Build and deployment kies je "Deploy from a branch".
7. Kies branch "main" en folder "/ (root)", klik Save.
8. Wacht tot GitHub Pages de site heeft gepubliceerd. Je krijgt een URL zoals
   https://JOUW-GITHUB-NAAM.github.io/forgefit/
   (gebruik de echte URL die GitHub toont; verzin deze niet).
9. Open die URL in Safari op je iPhone.
10. Tik op Deel (vierkant met pijl omhoog) → Zet op beginscherm → Voeg toe.
11. Open ForgeFit via het nieuwe beginscherm-icoon.

NAAR EEN ANDERE IPHONE STUREN
Stuur de gepubliceerde URL via WhatsApp, iMessage of AirDrop. De ontvanger opent de link in Safari en kiest Deel → Zet op beginscherm. Iedere telefoon heeft eigen lokale gegevens.

BELANGRIJK
- Dit is een eerste werkende versie, geen medisch hulpmiddel.
- De caloriebehoefte is een schatting, geen medische aanbeveling.
- Er is geen automatische voedseldatabase of barcode-scanner; voedingswaarden voer je zelf in.
- De gegevens staan lokaal per browser/app-installatie. Een back-upbestand kan handmatig worden overgezet.
- Voor updates: upload de gewijzigde bestanden opnieuw naar GitHub. Bij service-worker updates kan het helpen de app volledig te sluiten en opnieuw te openen.
